# HR Analytics Dashboard | Power BI

## About the Project
The HR Analytics Dashboard is a data analysis project developed using Power BI. It helps analyze employee information, hiring trends, demographics, and work locations to support better HR decision-making.

## Project Objectives
- Analyze total employee count.
- Calculate the average age of employees.
- Compare Headquarters and remote employees.
- Analyze hiring trends by year.
- Visualize gender distribution.
- Analyze employee distribution by state, department, and race.
- Identify insights and provide recommendations.

## Tools Used
- Power BI Desktop
- MySQL
- Git and GitHub

## Key Performance Indicators
- Total Employees
- Average Employee Age
- Headquarters Employees Percentage
- Remote Employees Percentage

## Dashboard Charts
- Hiring Trend by Year — Line Chart
- Gender Distribution — Donut Chart
- Employees by State — Bar Chart
- Employees by Department — Bar Chart
- Employees by Race — Bar Chart

## Key Insights
The dashboard helps identify hiring patterns, employee demographics, state-wise workforce distribution, department-wise employee counts, and the distribution of Headquarters and remote employees.

## Recommendations
- Monitor hiring trends for workforce planning.
- Review staffing levels across departments and states.
- Evaluate remote and Headquarters workforce distribution.
- Encourage fair and inclusive HR practices.
- Update the dashboard regularly with authorized data.

## How to View the Dashboard
1. Download this repository from GitHub.
2. Open the Power BI `.pbix` file using Power BI Desktop.
3. Configure the authorized data connection if required.
4. Explore the dashboard and its visualizations.
